# Задания по расчётам поездок

Синтетические задания для проверки работы агента с перепиской, чеками, валютами и взаиморасчётами. В собственной поездке имена, продавцы, покупки и курсы вымышлены; курсы используются для учебных расчётов.

- [Этап 1: поездка пяти друзей](trip-001/README.md) — условие и входные данные. Исходная таблица генератора, контрольные факты и готовые ответы хранятся отдельно и здесь не публикуются. Для решения достаточно таблицы и короткого отчёта; код необязателен.
- [Этап 2: обмен поездками](stage-2/README.md) — публичные результаты проверки внешних наборов, список «спорное», слой нормализации и воспроизводимый расчётный инструмент.
