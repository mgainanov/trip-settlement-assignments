# Задания по расчётам поездок

Синтетические задания для проверки работы агента с перепиской, чеками, валютами и взаиморасчётами. Все имена, продавцы, покупки и валютные курсы вымышлены. Курсы заданы для учебных расчётов, а не как сведения о реальном рынке.

Первое задание: [Поездка пяти друзей](trip-001/README.md).

Репозиторий содержит только условия и входные данные. Эталон и готовые ответы здесь не публикуются. Для решения достаточно таблицы и короткого отчёта; писать код необязательно.
